# 🎬 MuClip

**Нарезайте клипы из музыкальных видео *по словам* — а не по таймкодам.**

Вставляете ссылку на YouTube → видео транскрибируется с таймкодами для каждого
слова → выделяете нужные слова в транскрипте → FFmpeg рендерит точный клип.

</div>

---

## Что умеет

- 📥 Скачивает видео с YouTube / музыкальных сервисов (`yt-dlp`) и конвертирует в MP3 (`ffmpeg`)
- 🗣 Транскрибирует через **AssemblyAI** — точные таймкоды для каждого слова в миллисекундах
- 🤖 Опционально просит **DeepSeek** (через OpenRouter) подобрать самые «нарезочные» моменты — с выключенными reasoning-токенами, быстро и дёшево
- ✂️ Вы **выделяете слова** (или ищете фразу) и режете клип. Нарезка строго по границам слов, кодирование **NVENC → Intel QSV → CPU** в порядке приоритета
- 💬 Встроенный агент-чат: спросите *«найди припев»* или *«где он поёт про самолёт»* — получите готовые карточки с моментами, которые можно предпросмотреть и нарезать
- 🗂 Всё состояние хранится в одном `store.json` — без базы данных

## Как это работает

`YouTube URL → yt-dlp → ffmpeg (mp3) → AssemblyAI (таймкоды слов) → выбор диапазона слов → ffmpeg (NVENC/QSV/CPU) → готовый клип.mp4`

Слова — единица монтажа: нарезка происходит **строго по границам слов**, поэтому
начало и конец клипа идеально синхронизируются с речью. Если LLM предлагает
сцены, её цитата сопоставляется с индексами слов в транскрипте; всё, что нельзя
сопоставить дословно, безопасно отбрасывается.

## Требования

- **Python 3.10+** и [`uv`](https://docs.astral.sh/uv/)
- **FFmpeg** и **yt-dlp** в PATH (проба выполняется при старте, статус — в панели настроек)
- **API-ключ AssemblyAI** — речь в текст с таймкодами
- **API-ключ OpenRouter** *(опционально)* — подсказки сцен и агент-чат

## Быстрый старт

```bash
git clone <ваш-репозиторий> && cd muclip
uv sync                                            # установка зависимостей
mv .env.example .env && vim .env                   # впишите ключи, или…
# …введите ключи прямо в приложении (панель Settings) — они сохранятся в store.json
set -a; source .env; set +a
uv run server.py                                   # → http://127.0.0.1:8010
```

Альтернатива: `uv run uvicorn server:app --host 127.0.0.1 --port 8010`

## Конфигурация

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `MUCLIP_ASSEMBLY_KEY` | ключ AssemblyAI | — |
| `MUCLIP_OPENROUTER_KEY` | ключ OpenRouter | — |
| `MUCLIP_MODEL` | модель LLM (OpenRouter) | `deepseek/deepseek-v4-flash-0731` |
| `MUCLIP_HOST` | адрес запуска | `127.0.0.1` |
| `MUCLIP_PORT` | порт запуска | `8010` |

## Замечания

- `media/` и `store.json` в gitignore — видео, данные и ключи **никогда не попадают в репозиторий**.
- Клипы **перекодируются** (не копируются потоком), чтобы нарезка была покадрово точной к миллисекундным таймкодам AssemblyAI.
- Если аппаратный энкодер падает в рантайме, приложение молча переключается на CPU.
- Цитата LLM пропускается, если её нельзя сопоставить с транскриптом (применяется сопоставление без учёта пунктуации/пробелов).
- `language_detection` включён — работает с любым языком.
